# ダミーデータの投入方法

## 問題: ダミーデータが表示されない

ダミーデータが表示されない場合は、以下の手順でデータベースにダミーデータを投入してください。

## 方法1: 既存のデータベースにダミーデータを追加（推奨）

1. データベースが起動していることを確認
   ```batch
   docker ps
   ```
   `internet-banking-db` が表示されていることを確認

2. ダミーデータを投入
   ```batch
   init-dummy-data.bat
   ```

## 方法2: データベースをリセットして初期化

**警告**: この方法は既存のデータをすべて削除します。

```batch
reset-and-init-db.bat
```

その後、バックエンドとフロントエンドを起動:
```batch
start.bat
```

## 確認方法

1. フロントエンドにアクセス: http://localhost:3000
2. ダッシュボードで以下を確認:
   - 総残高: ¥4,800,000
   - 保有口座数: 4
   - 最近の取引: 10件

3. 各ページで確認:
   - `/accounts` - 4つの口座が表示される
   - `/transactions` - 10件の取引が表示される
   - `/investments` - 5件の投資情報が表示される

## トラブルシューティング

### エラー: コンテナが起動していない
```batch
start.bat
```

### エラー: データベース接続エラー
```batch
docker-compose restart postgres
timeout /t 10
init-dummy-data.bat
```

### エラー: データが重複している
`dummy-data.sql`は`WHERE NOT EXISTS`を使用しているため、重複して実行しても問題ありません。
既存のデータを削除したい場合は、`reset-and-init-db.bat`を使用してください。
